# 2D Coin Collector Game

A simple, interactive 2D browser game developed using HTML, CSS, and JavaScript.

This project was created to demonstrate my understanding of fundamental programming concepts, game development mechanics, and interactive web applications.

## About the Game

2D Coin Collector is a browser-based game where players collect coins while avoiding a moving enemy.

The objective is to collect as many coins as possible within 30 seconds without losing all three lives.

## Features

- **Player Movement:** Control the player using the keyboard arrow keys.
- **Coin Collection:** Collect randomly appearing coins to increase your score.
- **Moving Enemy:** Avoid an enemy that moves across the game screen.
- **Collision Detection:** Lose a life when the player touches the enemy.
- **Collision Protection:** Receive 1.5 seconds of protection after an enemy collision.
- **Score Tracking:** Earn points for each collected coin.
- **Countdown Timer:** Complete the game within 30 seconds.
- **Lives System:** Start each game with three lives.
- **Game Over Screen:** Displays the player's final score.
- **Restart Functionality:** Restart the game without refreshing the browser.

## Technologies Used

- **HTML5:** Structures the game and provides the canvas element.
- **CSS3:** Styles the game screen, background, and restart button.
- **JavaScript:** Handles player movement, game logic, collision detection, scoring, animation, and timer functionality.

## How to Play

1. Open the game in a web browser.
2. Use the arrow keys to move the green player.
3. Collect the gold coins to increase your score.
4. Avoid touching the red enemy.
5. Collect as many coins as possible before the timer reaches zero.
6. Click **Restart Game** to play again.
